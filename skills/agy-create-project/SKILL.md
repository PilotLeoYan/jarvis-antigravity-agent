# Project Scaffolding with agy

Standard operating procedure to initialize verified, production-ready repositories.

## Initialization Steps
1. Create directory structure under `projects/<category>/<project-name>`.
2. Initialize git repository: `git init`.
3. Create `README.md` containing architectural blueprint and setup instructions.
4. Establish workspace behavioral rules in `GEMINI.md` or `AGENTS.md`.
5. Set up dedicated virtual environment or dependency manifest (`pyproject.toml`, `requirements.txt`).
6. Produce clean initial git commit following conventional commit standards.
