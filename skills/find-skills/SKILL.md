# Find Skills

Guides the discovery and installation of community-contributed capabilities from the Open Agent Skills ecosystem.

## Usage
- Search for available skills via CLI:
  ```bash
  npx skills find [query]
  ```
- Install a skill into the agent environment:
  ```bash
  npx skills add <package>
  ```
- Update installed skills:
  ```bash
  npx skills update
  ```
